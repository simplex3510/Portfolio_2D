# RuneBlade(가칭) 입력 시스템 기획 — 스킬 입력

## 입력과 키 슬롯

- 스킬 입력 키 슬롯은 Q W E R A S D로, 총 7개 (키보드 키 기준)
- R은 궁극기 전용 고정 슬롯

### 키 슬롯과 스킬 할당

- 스킬은 키 슬롯에 할당해야 하며, R키를 제외한 별도 할당 제약 없음
- 키 슬롯에 스킬 할당 이후에도 다른 키 슬롯으로 변경 가능

## 입력 제스처

용어는 Tap(즉시 발동) / Charge(충전 발동) / Channel(지속 발동)으로 구성됨

- Tap
  - 입력 시점에 발동
- Charge
  - 유지 중 임계시간 이후 해제 시 발동
  - Charge 중 스킬 슬롯 입력은 및 이동 입력 무시
  - 임계시간 전에 떼면 취소
- Channel
  - 입력 시점에 발동하여 유지 시 발동 지속
  - 최대 유지 시간 없음

## 스킬 선입력 버퍼

- 버퍼는 최신 입력 1개만을 저장하며 갱신
- 저장 시점부터 일정 시간이 지나면 만료, 버퍼 비움
- 스킬이 진행 중이 아닐 때 버퍼 소비

## 공격 입력 시 제약

- 이동 입력 중 스킬 입력 시 우선하여 스킬 모션 재생, 이동 불가
