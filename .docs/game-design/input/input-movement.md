# RuneBlade(가칭) 입력 시스템 기획 — 이동 입력

## 이동 입력: 방향키

이동과 관련된 입력은 키보드 방향키의 조합으로 처리한다
이동 입력과 관련된 키는 고정적이며, 재할당 및 재배치가 불가하다

## 이동 종류

- 좌우 이동(← →)
- 좌우 회피(←← →→)
- 일반 점프(↑)
- 이단 점프(↑↑)
- 플랫폼 하강(↓↓).

## 이동 입력 규칙

- 좌우 이동 규칙
  - 동시 입력 시 선후를 따져 나중에 누른 쪽 이동
  - 동시 입력 중 나중에 누른 입력을 해제하면 아직 눌려있는 쪽 이동
- 좌우 회피 규칙
  - 공중 발동 불가
  - 회피 중 방향 전환 불가
- 점프 계열 규칙
  - 일반 점프는 지면에서만 발동 가능
  - 더블 점프는 공중에서만 발동 가능

## 일반 점프 선입력 버퍼

- 일반 점프는 선입력이 가능하며, 별도 버퍼를 가지고, 착지 시 소비하여 점프를 발동한다
- 선입력 버퍼는 공중에서 누른 ↑에만 적용.

## 더블탭 이력 규칙

- 더블탭 인식은 입력 이력 기준
- 더블탭 인정 구간은 첫 번째 입력을 기준으로 두 번째 입력까지의 간격으로 측정
- 더블탭 인식은 입력 방향키가 연속적으로 같을 경우에만 발생
  - 이전 입력 방향키와 현재 입력 방향키가 다르면 현재 입력 방향키를 첫 번째 입력으로 갱신
- 더블탭으로 판정되면 실행 여부와 무관하게 이력을 초기화
