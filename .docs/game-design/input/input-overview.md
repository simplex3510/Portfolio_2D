# RuneBlade(가칭) 입력 시스템 기획 — 개요

## 문서 구성

| 파일 | 범위 |
|---|---|
| `input-overview.md` | 전제, 입력 장치, 큰 원칙 |
| `input-movement.md` | 방향키, 대시 입력, 더블탭 이력, 점프 선입력 버퍼 |
| `input-skill.md` | 스킬 키 슬롯, 제스처, 선입력 버퍼|

## 작성 원칙

- 이 문서 묶음은 게임이 어떻게 동작해야 하는지(규칙)만 다룬다. 구현 방식은 다루지 않는다
- 규칙 하나는 하나의 파일에만 쓰고, 다른 파일에서 같은 규칙을 다시 쓰지 않는다. 문서끼리의 참조는 필요한 곳에서만 최소한으로 한다
- 문서에 기재된 규칙은 확정 사항이다. 기재되지 않은 사항은 확정이 아니다

## 전제

- Windows 키보드 전용. 마우스는 UI 전용(전투 입력 없음). 콘솔 패드 등 다른 입력 장치는 지원하지 않음
- 같은 순간에 들어온 여러 입력은 들어온 순서가 판정 근거이다
- 입력 처리는 실행 가능 판정과 중단 규칙으로 구분한다
