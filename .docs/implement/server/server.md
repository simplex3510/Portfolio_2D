# server.md

게임에 적용될 서버에 대한 구현 개발 지침 및 결정 사항들을 다루는 문서다.
구현 개발의 진행 상황은 다루지 않는다.

- **서버**
  - Unity에 의존하지 않는 독립 .NET 콘솔 프로그램이며, 별도 프로세스(Process, 독립적으로 실행되는 프로그램 단위)로 실행된다
  - 일정 간격(Tick)으로 시뮬레이션을 실행하고, 받은 입력을 틱 번호별로 적용한다
  - 룸 진행(대기 → 시작 → 종료)과 라운드 진행, 접속·끊김·재접속을 소유한다
  - 입력이 올바른지 확인하고(검증), 클라이언트의 데이터 및 상태는 서버 상태만 기준으로 판정한다
  - 현재 상태를 주기적으로 클라이언트에 보낸다(스냅샷, Snapshot). 이때 "어느 입력 틱까지 반영된 상태인지"를 함께 담는다
