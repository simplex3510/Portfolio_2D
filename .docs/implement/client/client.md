# client.md

게임에 적용될 클라이언트에 대한 구현 개발 지침 및 결정 사항들을 다루는 문서다.
구현 개발의 진행 상황은 다루지 않는다.

- **클라이언트**
  - 입력을 모아 틱 번호를 붙여 서버로 보낸다. 유실에 대비해 최근 틱의 입력을 함께 보낸다
  - 서버 상태를 받아 화면에 표시한다. 상대는 보간, 내 캐릭터는 예측과 보정을 적용한다
  - 서버보다 조금 앞선 틱을 돌아 입력이 제때 도착하게 한다
  - 호스트 모드에서는 서버 프로그램을 대신 실행해 주는 런처(Launcher, 다른 프로그램을 대신 띄워 주는 부분) 역할을 겸한다
